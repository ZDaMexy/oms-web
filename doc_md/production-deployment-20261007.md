服务器现有宝塔 PHP 8.2.28 不满足锁定依赖。F 盘构建独立 Alpine 3.24.2 / PHP 8.5.11 根目录，官方 APK 签名校验，固定版本及实际包清单随发布登记；不升级共享 PHP，不添容器守护进程，不在服务器编译。
